# מירוץ לשבת 🕯️

משחק דפדפן משפחתי בעברית מלאה (RTL): הכינו את כל הבית **לפני כניסת השבת** לפני שנגמר הזמן.
המשחק הוא **קובץ HTML יחיד** (`index.html`) עם Canvas ו-JavaScript וניל — בלי frameworks, בלי build step, בלי קבצים חיצוניים. פשוט פותחים בדפדפן או משתפים בוואטסאפ.

## איך משחקים
1. פותחים את `index.html` בכל דפדפן (מחשב או מובייל).
2. בוחרים רמת קושי ולוחצים **התחלה**.
3. נכנסים ל**בית מצויר במבט מהצד** — חדרים גדולים ומפורטים (מטבח, סלון ופינת אוכל, חדר שינה, כניסה) עם רהיטים, חלונות ושקיעה, ודמות שמהלכת בתוך החדר.
4. **מהלכים בחדר** עם חיצים ←→ / A-D או **הקשה על הרצפה**; עוברים בין חדרים דרך **הדלתות בצדדים** (הליכה לקצה או הקשה על הדלת).
5. מתקרבים לתחנה (השולחן, הכיריים, הארון…) ולוחצים Enter / מקישים — **המשימה קורית בתוך החדר**. עם ההשלמה החפץ משתנה: הנרות נדלקים, השולחן נערך, החלות מוכנות, הבית מתמלא לקראת שבת.
   - **סדר הכנות הגיוני:** יש משימות שנפתחות רק אחרי אחרות (מסומנות ב-🔒). קודם **קניות**, אחר כך **בישול/חלות/פרחים**, אז **פלטה** ו**סידור השולחן**, ובסוף — **הדלקת נרות** (רק כשהכל מוכן, ממש כמו בערב שבת).
6. כל משימה ממלאת את מד **"כמה מוכנים לשבת"** ומוסיפה ניקוד.
7. כשנגמר הזמן — מסך **"קבלת שבת"** עם סיכום, ניקוד, שיא והישגים.

## מערכות
- **ניקוד** לפי מהירות ודיוק · **מד התקדמות** ויזואלי · **הישגים** (למשל "הדלקת נרות בול בזמן", "הכל בלי לפספס").
- **דירוג כוכבים (1–3)** לכל משימה + **בונוס רצף (קומבו)**; הכוכבים מוצגים על החפצים בבית, במסך הסיום, ונשמרים כ"גביעים" ב-localStorage.
- **רצף סיום חגיגי** בהדלקת נרות — נרות זוהרים, ניגון שבת, "שבת שלום" וברכת הדלקת הנרות.
- **התאמה אישית לדמות** (בן/בת, צבע כיפה/סרט וחולצה — צנוע) שנשמרת; ו**קישוטי בית** שנפתחים כשצוברים כוכבים.
- **וריאציות** — כל אחת מ-10 המשימות מקבלת וריאנט אקראי (מספר פריטים, מהירות, סידור, מכשולים), כך שכל משחק שונה.
- **מכניקות חלופיות** שמתחלפות בתחנות: קיפול בגדים (החזק-ושחרר), טאטוא (גרירה), ומזיגת יין לגביע (הקש-לעצור).
- **אתגר יומי 📅** — כולם מקבלים *אותו* אתגר לפי התאריך (seed קבוע). בסיום כפתור **"שתף תוצאה"** מעתיק טקסט לוואטסאפ (ניקוד+כוכבים+תאריך), עם **שיא יומי** ו**רצף ימים** 🔥. הכל אופליין — ההשוואה עם חברים ידנית.
- **מיני-אירועים / אורחים לשבת 🤝** — מדי פעם קופץ אירוע (🚪 אורח בדלת · 📞 סבתא בטלפון · 🍰 שכן עם עוגה · 👶 תינוק מתעורר · 🧺 כביסה יבשה) עם באנר וספירה לאחור. **הקשה / Enter** בזמן = בונוס ניקוד (מהיר = יותר), פספוס = האורח הולך בלי בונוס. הישג **"מכניס/ת אורחים"** על 3 בריצה, וסיכום כמה אורחים אירחת במסך הסיום. האירועים נעצרים בזמן משימה ולא מופיעים סמוך לכניסת השבת.
- **עונות ומזג אוויר 🌦️** — אביב 🌸 / קיץ ☀️ / סתיו 🍂 / חורף 🌧️ (או **"לפי היום"** שנקבע אוטומטית מהחודש). כל עונה משנה את **שעת השקיעה** (בקיץ שבת נכנסת מאוחר = יותר זמן, בחורף מוקדם = פחות זמן), את **פלטת השמיים וצבע השמש** בחלונות, ואת **האפקט בזגוגית** (גשם / פרחים / עלים נושרים). באתגר היומי העונה נקבעת לפי התאריך כדי שתהיה זהה לכולם.
- **רמות קושי**: קלה / בינונית / קשה + מצב **תרגול** בלי הגבלת זמן.
- **סאונד מסונתז** (Web Audio) — מנגינת רקע עדינה ואפקטים, עם **כפתור השתקה** (או מקש `M`). ההעדפה נשמרת.
- **מסך מלא** — כפתור ⛶ (ב-HUD ובמסך הפתיחה) למעבר למסך מלא; הפריסה ממלאת את גובה המסך במובייל ונשארת בפורמט דיוקן במחשב.
- **שמירת שיא אישי** ב-`localStorage`.
- תמיכה מלאה ב**עכבר, מגע ומקלדת**; רספונסיבי למובייל.

## מבנה הקוד (קובץ יחיד, מודולרי)
בתוך `index.html`:
`GameState` (מצב מרכזי) · `AudioManager` · `AchievementManager` · `ALL_GAMES` (מערך של 10 סצנות בעלות ממשק אחיד: `enter/update/render/onPointer/onKey/finish`) · `Hub` (בית מצויר במבט מהצד — חדרים גדולים עם רהיטים במצב רגיל/מוכן, דמות מונפשת שמהלכת, ומעבר בין חדרים דרך דלתות) · `SceneManager` (מפעיל את המשימה **בתוך פאנל בחדר**, ממפה קלט חזרה למרחב-המשימה, ומחזיר לחדר עם עדכון מצב-"מוכן" לרהיט) · לולאת `requestAnimationFrame` · מאזיני קלט מאוחדים · עוזרים כולל `txt()` לציור טקסט RTL על הקנבס.

להוספת חדר או משימה: מוסיפים אובייקט סצנה ל-`ALL_GAMES`, ומוסיפים תחנה (עם ציור מצב רגיל/מוכן) לחדר המתאים ב-`Hub.build`.
כדי להוסיף משימה חדשה: יוצרים אובייקט סצנה עם אותו ממשק ומוסיפים אותו למערך `ALL_GAMES`.

## בדיקה
נבדק ב-Chromium (Playwright): כל 10 הסצנות נטענות, אפס שגיאות קונסול, שמירת שיא נשמרת בין הרצות, ו-RTL תקין בכל המסכים.
